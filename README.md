## О проекте

**Sensa** — мобильное приложение для чтения электронных книг в формате EPUB, позволяющее не только читать книги, но и создавать цветные заметки и цитаты, организовывать совместные сессии чтения и обмениваться мнениями в реальном времени.

### Основные возможности

| Возможность | Описание |
|-------------|----------|
| **Личное чтение** | Чтение книг с возможностью выделения текста, создания цветных цитат и заметок |
| **Совместные сессии** | Создание сессий с ролевой моделью (админ/участник) и приглашение участников по ссылке |
| **Ответы на заметки** | Древовидная структура обсуждений внутри сессий |
| **Приватность** | Публичные и приватные заметки с гибкими правилами видимости |
| **Уведомления** | Мгновенные уведомления через WebSocket о новых заметках и ответах |
| **Настройки** | Изменение размера шрифта и цветовой темы интерфейса |

### Правила видимости заметок в сессиях

| Тип заметки | Автор | Кто видит | Выделение в тексте |
|-------------|-------|-----------|-------------------|
| Цитата | Любой | Только автор | Цветной фон |
| Приватная заметка | Любой | Только автор | Цветное подчёркивание |
| Публичная заметка | Участник | Только админ | Серое подчёркивание |
| Публичная заметка | Админ | Все участники | Серое подчёркивание |

## Установка и запуск

### Требования

- **Docker** и **Docker Compose** (для бэкенда)
- **Node.js** 18+ и **npm/yarn** (для фронтенда)
- **Expo Go** на мобильном устройстве (для тестирования)

### 1. Запуск бэкенда

```bash
# Клонирование репозитория
git clone https://github.com/vndtr/Sensa.git
cd Sensa/Backend

# Создание файла .env (настройте по образцу)
cp .env.example .env

# Запуск контейнеров
docker-compose up -d
```

После запуска станут доступны:

| Сервис | Адрес |
|--------|-------|
| FastAPI API | `http://localhost:5000` |
| Swagger UI (документация) | `http://localhost:5000/docs` |
| Adminer (управление БД) | `http://localhost:8080` |
| MinIO Console | `http://localhost:9001` |

### 2. Запуск фронтенда

```bash
cd Sensa/ReadEduMobile

# Установка зависимостей
npm install

# Запуск Expo
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** на мобильном устройстве или запустите в эмуляторе.

### 3. Настройка переменных окружения (фронтенд)

Создайте файл `.env` в корне `Frontend`:

```env
EXPO_PUBLIC_API_URL=http://192.168.1.100:5000  # IP вашего компьютера в сети
EXPO_PUBLIC_WS_URL=ws://192.168.1.100:5000     # Для WebSocket
```

## Основные экраны приложения

| Экран | Описание |
|-------|----------|
| **AuthScreen** | Регистрация и авторизация пользователя |
| **HomeScreen** | Главный экран с последней книгой и активными сессиями |
| **LibraryScreen** | Управление библиотекой книг (добавление, удаление) |
| **SessionsScreen** | Список сессий совместного чтения |
| **SoloReader** | Режим личного чтения с аннотациями |
| **SessionReader** | Режим совместного чтения (роли, ответы, WebSocket) |
| **ProfileScreen** | Профиль пользователя и настройки |

## API Эндпоинты (основные)

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| POST | `/auth/signup` | Регистрация пользователя |
| POST | `/auth/login` | Вход и получение JWT-токена |
| POST | `/book/` | Добавление книги (multipart/form-data) |
| GET | `/book/` | Получение всех книг пользователя |
| POST | `/session/` | Создание сессии совместного чтения |
| POST | `/session/note/create` | Создание заметки в сессии |
| POST | `/session/quote/create` | Создание цитаты в сессии |
| POST | `/session/note/delete` | Удаление заметки |
| WebSocket | `/ws/session/{id}` | Уведомления в реальном времени |

> Полная документация доступна по адресу `http://localhost:5000/docs`
